# Retry-Storm Livelock: BCSE303L project

Predicting and pre-empting retry-storm-induced livelock in microservices.

| Folder / file | What is in it |
|---|---|
| `Report_and_Slides.pdf` | **For the assessment:** the IEEE-format report (16 pages) and the 20 Review-3 slides, in one PDF |
| `Report_IEEE.pdf` | The IEEE-format report on its own (16 pages: design, dataset, detection, prediction, controller, implementation, results, user guide) |
| `report/` | LaTeX source of the report (`Report_IEEE.tex`, opens in Overleaf) and its figures: plots drawn by `code/report_plots.py`, diagrams drawn in LaTeX (`figs/tikz_*.tex`) |
| `Review3_Final.pptx` / `.pdf` | The final (Review-3) deck: 20 slides in the demo's order: what we used, how each output is produced, the outputs, and how accuracy is calculated |
| `DEMO_PROCEDURE.md` | Step-by-step procedure for the demo-only final review |
| `PROJECT_EXPLAINED.md` | The whole project explained from first principles: background, testbed internals, the storm mechanism, dataset, detection, prediction, evaluation, controller, experiments, limitations, code map, self-test |
| `PRESENTATION_GUIDE.md` | How to present the deck and run the demo, and why every file in this folder exists |
| `code/` | The whole project: testbed, detection, prediction, controller, experiments, tests. **Start with `code/README.md`.** |
| `code/QUICKSTART.md` | Demo-day commands, in order |
| `code/results/RESULTS.md` | Every result number in one place, generated by `code/run_pipeline.py` |
| `code/results/model_evaluation.txt` | Full evaluation of the prediction model: MCC, ROC-AUC, calibration, 95% intervals, run-time cost |
| `code/results/figures/` | All figures for the report and slides |
| `code/data/` | The generated dataset (raw logs, labelled windows, scenario list) |
| `docs/VIVA_QA.md` | Question bank for the review, with answers |
| `docs/CODE_WALKTHROUGH.md` | Follows one request through the code, then one analysis |
| `docs/DATASET_SEARCH.md` | Public datasets checked, what each lacks, links |
| `figures/` | Architecture diagrams from Review 2 (not used by the Review-3 deck) |
| `DELETE/` | The old 57-slide deck, kept just in case (ignored by git; safe to delete) |
